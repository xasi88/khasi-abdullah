## Состояние на вечер 7 октября 2026 года — читать первым

- В Cloudflare записи `xasi88.ru` (четыре A) и `www` (CNAME) переведены в режим «DNS only». Запись `tanwin` не менялась. Теперь адрес сайта ведёт напрямую на GitHub.
- По `http://` сайт открывается. По `https://` браузер показывает предупреждение о сертификате: GitHub Pages ещё не выпустил сертификат для `www.xasi88.ru`.
- Осталось: в GitHub (репозиторий → Settings → Pages) убрать и заново задать домен `www.xasi88.ru`, дождаться сертификата (до часа) и включить «Enforce HTTPS». ИИ-агенту этот шаг запретила система разрешений сессии, решение за автором.
- Запасной путь: вернуть пяти записям режим «Proxied» в Cloudflare — сайт вернётся к прежнему состоянию.

## Известная проблема: сайт открывается не у всех (история вопроса)

Записи `xasi88.ru` и `www` в Cloudflare стоят в режиме «Proxied». В России соединения через сеть Cloudflare обрываются после первых килобайт, поэтому страница не догружается. Замер 7 октября 2026 года с компьютера автора: через Cloudflare — обрыв за 25 секунд, напрямую с GitHub — 0,3 секунды.

Cloudflare подключили, потому что GitHub Pages не выдал сертификат HTTPS для домена (со слов автора). У `tanwin.xasi88.ru` на том же домене сертификат GitHub есть, и запись стоит в режиме «DNS only» — значит, путь рабочий.

Что нужно сделать (решение автора, в отдельной сессии с запасом времени):

1. В панели Cloudflare перевести записи `xasi88.ru` и `www` в режим «DNS only» — так уже настроена запись `tanwin`.
2. Дождаться, пока GitHub Pages выпустит сертификат для `www.xasi88.ru`, и включить «Enforce HTTPS». До выпуска сертификата браузер показывает предупреждение о безопасности; обычно это до часа.
3. Если сертификат не появился за сутки — вернуть режим «Proxied» и искать причину (записи CAA и лишние записи A/AAAA у домена).

Пока записи не переключены, не утяжеляйте `index.html`: через Cloudflare проходит только начало соединения. 7 октября 2026 года попытка собрать страницу в один файл (20 КБ вместо 10,8 КБ в сжатом виде) сделала сайт недоступным и была отменена — см. `docs/DECISIONS.md`.

## Открыть сейчас

Preview открывается по адресу [http://localhost:4173/](http://localhost:4173/) после запуска. Из корня проекта выполните:

```powershell
npm run preview
```

Остановить preview: `Ctrl+C` в том же окне PowerShell.
