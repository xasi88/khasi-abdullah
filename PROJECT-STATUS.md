## Открыть сейчас

Preview открывается по адресу [http://localhost:4173/](http://localhost:4173/) после запуска. Из корня проекта выполните:

```powershell
npm run preview
```

Остановить preview: `Ctrl+C` в том же окне PowerShell.

## Что уже готово

- документальный одностраничный сайт с адаптивной компоновкой (дизайн v2, светлая основа);
- навигация, мобильное меню, нативные раскрывающиеся блоки, хронология и копирование публичного Instagram handle;
- семантика, видимый фокус и reduced motion;
- модульная структура исходников, нулевые runtime-зависимости, README и QA-инструкции;
- главный портрет в hero и групповое фото близких друзей в разделе «История» — оба из `@xasi88`, подтверждены автором;
- 20 обложек видео/рилсов из собственных Instagram и YouTube автора, подключены по клику без внешних запросов при загрузке;
- JUMMA подтверждена как живой проект (jumma.site) и добавлена ссылка; книга связана со страницей на LiveLib.

1. Домен и хостинг — как только выбраны, добавим favicon, `og:image`, `robots.txt`, `sitemap.xml` и разошлём по хостингу.
