# Дизайн-система

**Версия 2 (21 сентября 2026).** Предыдущий тёмный вариант сохранён в `archive/design-v1-prototype.zip`.

## Принцип

Тёплый документальный editorial: бумажный фон с едва заметной фактурой, плотный графит, зелёный акцент для действий и статусов, шафран как редкий сигнал. Страница светлая; тёмный фон (`#1D2821`) использован ровно дважды — как смысловая пауза: **HurmaN** (важная, но незавершённая цель) и финальный блок **«Связь»** с подвалом. Выразительность строится на типографике, сетке, ритме и реальных материалах, а не на декоре.

## Токены (`src/styles/tokens.css`)

| Роль | Значение |
| --- | --- |
| Фон страницы | `--paper` `#F4F1EA` |
| Чередующиеся тона секций | `--paper-deep` `#E8E2D6`, `--sage` `#E1E7DA` |
| Поверхность карточек | `--surface` `#FBF9F4` |
| Тёмная поверхность | `--forest` `#1D2821` |
| Основной текст | `--ink` `#182019` (вторичный `--fg-muted` `#48554D`) |
| Зелёный акцент | `--moss` `#2E5942` |
| Шафрановый сигнал | `--saffron` `#D7A94B` — только заливки, линии и текст на тёмном |
| Акцентный текст на светлом | `--ochre` `#7A5710` (шафран на светлом не проходит контраст) |
| Serif / Sans | Georgia / Arial (системные, без внешних шрифтов) |
| Шаг отступов | `--s-1…--s-8` = 4, 8, 12, 16, 24, 32, 48, 64 px |

Компоненты используют **ролевые переменные** (`--bg`, `--fg`, `--accent`, `--mark`, `--rule`, `--card`). Классы `.is-dark`, `.tone-deep` и `.tone-sage` на секции переопределяют только их — поэтому один и тот же компонент корректно выглядит на светлом и тёмном фоне.

## Типографика

Заголовки и повествовательный текст — serif (`prose`: 19–22 px, интерлиньяж 1.6). Навигация, подписи, статусы и цифры-метки — sans. Размеры через `clamp()`. База 18 px (17 px на телефоне); текст короче 12 px не используется, мелкие подписи 13–14 px.

## Компоненты (`src/styles/components/`)

| Файл | Что это |
| --- | --- |
| `section-layout.css` | `.section`, 12-колоночная сетка, левая «рейка» с номером и названием (sticky), `.split-heading` |
| `labels.css` | eyebrow с номером, status-чипы, fine-print, chips |
| `print.css` | фото как документальный отпечаток: рамка, подпись с индексом |
| `clip.css` | карточка медиа: обложка, метка источника (YouTube/Reels), длительность, подпись с датой. YouTube-карточка — кнопка: по клику подставляется iframe `youtube-nocookie.com`; Instagram-карточка — ссылка. Сетки `.clip-grid`, `--2`, `--tall` (9:16) |
| `disclosure.css` | нативный `details` как карточка (инициативы, проекты) |
| `card.css`, `note.css`, `prose.css`, `button.css` | карточка, заметка «нужны материалы», текст, кнопки |
| `site-header.css`, `site-footer.css` | липкая шапка, мобильное меню, подвал |

## Сетка и адаптивность

- **Десктоп (от 1100 px):** 12 колонок; рейка секции занимает 3, содержимое — 9.
- **Планшет (до 1100 px):** рейка превращается в строку-метку над содержимым, внутренние блоки — в две колонки; при 900 px заголовок и лид становятся в столбец, меню складывается.
- **Телефон (до 560 px):** одна колонка, боковые отступы 16 px.
- Нажимаемые зоны — минимум 44×44 px. Адаптивные правила лежат в конце того же CSS-файла, который они меняют.
