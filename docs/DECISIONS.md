# Принятые решения

| Дата | Решение | Причина |
| --- | --- | --- |
| 2026-09-21 | HTML вынесен в фрагменты, CSS и JS — в модули `src/` | Следующему разработчику проще находить и менять один смысловой слой без монолитных файлов |
| 2026-09-22 | Главный портрет в hero заменён на кадр из `p/CmwGBu0oKbo` (прямая ссылка от автора); прежнее групповое фото `community.webp` перенесено в раздел «История» с новой подписью про друзей детства | Автор прислал ссылку на качественное фото для hero и отдельно попросил не терять групповой кадр — эти люди важны для него |
| 2026-09-22 | `og:description` в `head.html` больше не упоминает «локальный прототип» | Осталось от домакетной версии; при подготовке к покупке домена такая фраза в превью ссылки вводила бы в заблуждение |
| 2026-09-22 | JUMMA переведена из статуса «разработка» в «реальные посетители», добавлена ссылка на jumma.site | Автор дал рабочий адрес; проверка вживую показала активный клуб с матчами за последние дни. Имена игроков клуба намеренно не перенесены на личный сайт |
| 2026-09-22 | В подвале появилась строка «Идея и тексты — мои, вёрстку и код собрал ИИ-ассистент»; убрана метка «Локальный прототип» | Пользователь прямо попросил указать участие ИИ-ассистента в создании сайта |
| 2026-09-22 | Служебные TODO-пометки («Нужен архив», «Нужны фото», «Нужны источники» и т.п.) переписаны в первом лице как обычные авторские подписи, смысл (что ещё не подтверждено) сохранён | Прежние формулировки читались как заметки разработчика, а не голос автора; пользователь попросил текст, который звучит естественно и не как черновик |
| 2026-09-21 | Медиа из собственных Instagram и YouTube автора: локально хранятся только обложки; YouTube воспроизводится по клику через `youtube-nocookie.com`, Instagram открывается ссылкой | Видеофайлы без входа в аккаунт недоступны; так сохраняется правило «без внешних сервисов»: до клика сайт не обращается к YouTube/Meta и не грузит их скрипты. Клик — осознанное действие посетителя |
| 2026-09-21 | Не используются обложки с телефонами, третьими лицами, кадрами «лёжа» и очень личными сюжетами | Соблюдение `EDITORIAL-STYLE.md` и приватности; список исключённого — в `MATERIALS.md` |
| 2026-09-21 | Компонент-заглушка `slot` удалён | Разделы, где стояли placeholder, получили реальные материалы; недостающее описывается заметкой `note` |
| 2026-09-21 | Дизайн v2: светлая страница, тёмный фон только у HurmaN и «Связи»; рейка секций, фото-«отпечатки», ролевые CSS-переменные | Прежний вариант был почти наполовину тёмным (5 секций из 14) и не соответствовал концепции «тёплая светлая основа»; мелкий текст был 10–12 px. Тексты и факты не менялись. Старая версия — `archive/design-v1-prototype.zip` |
| 2026-09-21 | Одна секция — один HTML- и один CSS-файл с одинаковым именем; лимит 150 строк на файл в `npm run check` | Первое разделение оставило 5 HTML-файлов на 14 секций и общие `sections.css`/`responsive.css`; пользователь просил чёткую структуру без раздутых файлов |
| 2026-09-21 | Слой `responsive` убран: `@media` лежат рядом с правилами, которые меняют | Адаптив секции правится в том же файле, что и её вид; проверено сравнением вычисленных стилей на 1440, 768 и 375 px — идентичны прежним |
| 2026-09-21 | Добавлены нативный build/check и `package.json` без зависимостей | Статический сайт остаётся лёгким, но сборка и проверка становятся воспроизводимыми на Windows |
| 2026-09-21 | `index.html` стал сгенерированным preview/deploy-артефактом | Браузер по-прежнему открывает проект через простой статический сервер, а исходники остаются модульными |
| 2026-09-21 | Реализован один вариант, не набор тем | Пользователь просил законченный интерактивный прототип для дальнейших правок |
| 2026-09-21 | Выбран static HTML/CSS/JS без сборки | Лёгкий поддерживаемый стек, быстро открывается локально и понятен следующему разработчику |
