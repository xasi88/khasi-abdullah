# Следующие этапы

## 1. Редакционный отбор

Собрать только разрешённые материалы из `MATERIALS.md`; выбрать главный портрет и решить, какие истории заслуживают отдельного визуального блока. На этом этапе уточнить статусы всех цифровых продуктов и дату/ссылку книги, если они должны быть публичными.

## 2. Контентная правка

Заменить placeholders, добавить подтверждённые подписи, материалы медиа и актуальные скриншоты приложений. Не расширять перечень достижений без источника.

## 3. Финальный UX

Проверить ритм страницы с реальными фото, контраст текста на изображениях, порядок блоков и доступность. При необходимости добавить один-два осмысленных взаимодействия, не перегружая документальный формат.

## 4. Подготовка к публикации

Сделано: домен и GitHub Pages, canonical, sitemap, robots, Open Graph image, favicon (22 сентября 2026); стили и сценарии встраиваются в `index.html` при сборке, есть предупреждение о сети (7 октября 2026).

Осталось: перевести записи `xasi88.ru` и `www` в Cloudflare в режим «DNS only», дождаться сертификата GitHub Pages и включить «Enforce HTTPS» — подробности в `ARCHITECTURE.md`, раздел «Хостинг и адрес». Аналитика — только при отдельном решении пользователя; при появлении форм или аналитики нужна понятная политика конфиденциальности.

## 5. Репозиторий и релиз

После контентного утверждения создать отдельный GitHub-репозиторий при явном решении пользователя, настроить CI только если он нужен, и опубликовать статическую версию. Текущий локальный Git к этому подготовлен, но не опубликован.
