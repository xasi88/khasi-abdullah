- [ ] `npm run check` завершился без ошибок.

## Контент и доверие

- [ ] Нет новой точной даты, ссылки, имени, суммы или статуса без записи в реестре фактов.
- [ ] Дороги и другие инициативы описаны как коллективная работа.

- [ ] Каждый новый материал есть в `MATERIALS.md` с источником и статусом.
