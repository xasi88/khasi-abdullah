# Как продолжать проект

## Обычный цикл

1. Прочитайте `PROJECT-STATUS.md` и `docs/DOCUMENTATION-INDEX.md`.
2. Вносите разметку в `src/content/`, стили в `src/styles/`, поведение в `src/js/`.
3. Выполните `npm run build`.
4. Выполните `npm run check`.
5. Откройте `http://localhost:4173/` и вручную проверьте desktop, планшет и узкий экран.
6. Если изменились факты, статусы или материалы, обновите соответствующую документацию одновременно с кодом.

## Принципы изменений

- Одна смысловая задача — один логичный набор файлов; не прячьте новый код в монолитный файл.
- Не добавляйте dependency без причины, альтернативы и инструкции по использованию в `docs/DECISIONS.md`.
- Не добавляйте форму, email, телефон, публичные ссылки, логотипы СМИ или фотографии без исходника и разрешения.
- Placeholders не заменять стоками или синтетическими портретами.
- Визуальные изменения сверяйте с `docs/DESIGN-SYSTEM.md` и `docs/ACCESSIBILITY-AND-RESPONSIVENESS.md`.

## Git

Проект локально инициализирован. До первого коммита проверьте `git config user.name` и `git config user.email`; чужие данные не подставляйте. Публикация на GitHub не входит в текущую задачу.
