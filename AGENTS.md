# Локальные правила проекта

## Цель

Это локальный reviewable-прототип личного документального сайта Хаси Абдуллаха. Приоритет — сохранение фактической точности, спокойного тона и понятной структуры для следующего человека или AI-агента.

## Как работать

- Меняйте исходники в `src/`, а затем запускайте `npm run build`.
- Не правьте сгенерированный `index.html` вручную: он собирается из `src/templates/page.html` и фрагментов в `src/content/`.
- Одна секция — это `src/content/sections/<имя>.html` и парный `src/styles/sections/<имя>.css`; адаптив (`@media`) пишите в конце того же CSS-файла. Файлы не длиннее 150 строк: не сваливайте новое в существующий файл, разделяйте по смыслу (`npm run check` это проверяет).
- Перед передачей запускайте `npm run check` и проверяйте preview в браузере.
- Новые изображения кладите только в `assets/images/` (обложки видео — в `assets/images/media/`) с понятным именем; источник, дата и разрешение фиксируются в `docs/MATERIALS.md`.
- Перед добавлением обложки посмотрите её саму: телефоны, банковские данные, имена и лица третьих лиц, кадры с акцентом на болезнь на сайт не идут. Внешние сервисы (YouTube и др.) — только по клику посетителя, не при загрузке страницы.
- Для каждого нового публичного факта сначала обновляйте `docs/FACTS-AND-OPEN-QUESTIONS.md` и только затем текст страницы.

## Редакционные границы

- Не делать инвалидность маркетинговой темой и не использовать жалостливые или героизирующие штампы.
- Не приписывать Хаси единолично результаты коллективных инициатив.
- Не заявлять HurmaN как открытый/завершённый проект.
- Не выдумывать даты, ссылки, медиа-материалы, изображения и статусы цифровых продуктов.

Полные правила: `docs/EDITORIAL-STYLE.md`, `docs/CONTENT-MODEL.md` и `docs/MATERIALS.md`.
